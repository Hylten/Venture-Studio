# Hyltén Venture Studio - Alpha Operating System

This is the "Institutional Industrial" flagship website for Hyltén Invest's Venture Studio, featuring the **Alpha Operating System (OS)**.

## Key Features
- **Institutional Design**: Dark mode (#050505) with Titanium Gold (#C5A059) accents.
- **Roials Alpha Engine**: Real-time terminal visual showcasing origination velocity.
- **Bento Grid Architecture**: Clean, high-performance layout for features and team.
- **Qualification Filter**: Multi-step conditional form for Founders Beta program.
- **Stack**: Vite + React + Framer Motion + Lucide React.

## Getting Started

1. `npm install`
2. `npm run dev`

## Site Architecture
1. **Hero**: Alpha Operating System positioning.
2. **Roials Alpha**: Proprietary AI-origination engine visual.
3. **The DNA**: Gnosjöandan meets GTM Engineering.
4. **Founders Beta**: 30-day hardening program (Fas 1).
5. **Venture Studio**: Capital expansion networks (Fas 2 & 3).
6. **Inkubera Filter**: High-authority qualification form.
